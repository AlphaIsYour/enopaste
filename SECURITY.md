# Security Policy

## Supported Versions

We release patches and security fixes for the latest version of EnoPaste.

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

The EnoPaste team takes security vulnerabilities seriously. If you discover a security flaw or potential vulnerability in this project, **please do NOT report it via a public GitHub issue**.

Instead, please report it via one of the following methods:

1. **GitHub Security Advisory (Recommended):**
   Submit a private advisory via [GitHub Security Advisories](https://github.com/AlphaIsYour/youralpha-07-enopaste/security/advisories/new).

2. **Direct Contact:**
   Reach out directly to the maintainer with details regarding the vulnerability.

### When reporting, please provide:
* A description of the issue and its potential impact.
* Detailed steps or a minimal proof of concept (PoC) to reproduce the vulnerability.
* Any potential mitigations or suggested fixes, if known.

### What to expect:
* We will acknowledge receipt of your vulnerability report within 48 hours.
* We will keep you updated as we investigate and work on a fix.
* Once resolved, we will publish a release and credit your responsible disclosure (unless you prefer to remain anonymous).
